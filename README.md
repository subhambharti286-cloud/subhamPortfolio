## 🚀 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/subhambharti286-cloud/subhambhartiPortfolio.git
cd subhambhartiPortfolio
`

### 2. Launch Local Streaming Server
To enable HTTP 206 partial range streaming for 4K video playback:
`powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
`
Or simply double-click **start_server.bat** on Windows.

### 3. Open in Browser
Visit **[http://localhost:8080](http://localhost:8080)** (or double-click Open_Portfolio.url).
